Unofficial fan project

Shadow Empire Inspector is an unofficial, fan-made reference and learning tool created to help players understand Shadow Empire. It is not affiliated with, endorsed by, or sponsored by VR Designs.

Attribution

Shadow Empire is developed by VR Designs and published by Matrix Games. Shadow Empire names, game-derived data and other game intellectual property remain the property of their respective rights holders. The Inspector interface, original explanatory material and original Inspector artwork are separate fan-project material.

How this was built

Human-directed, AI-assisted. Product direction, gameplay questions, testing and design decisions were human-led. OpenAI ChatGPT was extensively used for programming, data analysis, reverse-engineering assistance, documentation and interface development.

AI-generated conclusions are not treated as authoritative on their own. Where possible, mechanical claims are grounded in extracted Shadow Empire game data or verified against the matching game executable, with official documentation used as supporting reference.

Project purpose

The project is intended as a non-commercial reference and learning tool, with a planned open-source release subject to appropriate permissions and licensing. Extracted game data is presented to explain and cross-reference game systems. Technical View preserves source/provenance information and distinguishes extracted values, executable-derived mechanics and Inspector interpretation.

Data provenance

Current reference build: game executable build 1.32.264 + vanilla data library 1.32a, extracted from the same installed game. Oceania and Republica remain WIP until their data is imported.
